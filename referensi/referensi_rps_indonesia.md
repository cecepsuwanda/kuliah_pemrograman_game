# Referensi RPS Pemrograman Game dari Perguruan Tinggi Indonesia

Dokumen dan halaman berikut dipilih berdasarkan kemiripannya dengan CPMK mata kuliah **Pengantar Pemrograman Game**, yaitu:

1. game loop dan fisika sederhana menggunakan Python/Pygame;
2. algoritma AI dasar untuk NPC;
3. penggunaan game engine Unity/Godot untuk membangun level; dan
4. integrasi aset audio dan visual.

Tidak ditemukan satu RPS publik yang sama persis dengan pembagian Python/Pygame pada CPMK1–CPMK2 dan game engine pada CPMK3–CPMK4. Karena itu, referensi di bawah dapat dikombinasikan saat menyusun RPS.

## RPS dengan Kemiripan Tertinggi

### 1. Institut Teknologi Sepuluh Nopember — Desain dan Pemrograman Game

- Institusi: Institut Teknologi Sepuluh Nopember (ITS)
- Program studi: Teknik Komputer
- Bentuk: RPS dalam PDF
- Kesesuaian: sangat tinggi
- Cakupan relevan: teknologi game, algoritma, Game Design Document, Unity, dan *Computational Intelligence* pada game.
- Kaitan CPMK: mendukung CPMK2, CPMK3, dan pengembangan solusi komputasi pada CPL.
- Tautan: [RPS Desain dan Pemrograman Game ITS (PDF)](https://www.its.ac.id/komputer/wp-content/uploads/sites/28/2018/03/Desain-dan-pemograman-Game.pdf)

### 2. Universitas Negeri Manado — Pengembangan Game

- Institusi: Universitas Negeri Manado (UNIMA)
- Program studi: Teknik Informatika
- Bentuk: RPS berbasis web, tahun ajaran 2025/2026
- Kesesuaian: tinggi
- Cakupan relevan: konsep game, Game Design Document, mekanik permainan, pembuatan prototipe menggunakan Unity/Unreal, interaktivitas, efek, pengujian, evaluasi, dan publikasi game.
- Kaitan CPMK: sangat relevan untuk CPMK3 dan CPMK4 serta aspek implementasi dan evaluasi pada CPL04.
- Tautan: [RPS Pengembangan Game UNIMA](https://ti.unima.ac.id/rps/view/11)

### 3. Universitas Negeri Surabaya — Pemrograman Game

- Institusi: Universitas Negeri Surabaya (UNESA)
- Program studi: S1 Pendidikan Teknologi Informasi
- Bentuk: halaman mata kuliah dan RPS PDF
- Kesesuaian: tinggi
- Cakupan relevan: konsep, desain, dan implementasi game dengan dukungan Unity, Blender, dan perangkat multimedia.
- Kaitan CPMK: mendukung CPMK3 untuk penggunaan engine serta CPMK4 untuk pengolahan dan integrasi aset visual.
- Tautan:
  - [Halaman Mata Kuliah Pemrograman Game UNESA](https://sindig.unesa.ac.id/mk/s1-pendidikan-teknologi-informasi/pemrograman-game)
  - [RPS Pemrograman Game UNESA (PDF)](https://sidia.unesa.ac.id/rps-pdf/s1-pendidikan-teknologi-informasi/pemrograman-game.pdf)

## Dokumen Kurikulum dan Mata Kuliah yang Sangat Relevan

### 4. Politeknik Negeri Batam — Kurikulum Teknologi Permainan

- Institusi: Politeknik Negeri Batam
- Program studi: Teknologi Permainan
- Bentuk: dokumen kurikulum program studi dalam PDF
- Kesesuaian: sangat tinggi sebagai referensi cakupan materi
- Cakupan relevan: Pemrograman Gim, fisika permainan, grafika komputer, serta kecerdasan buatan untuk permainan. Tujuan pembelajarannya mencakup pembangunan dan integrasi komponen grafika, fisika, dan AI.
- Kaitan CPMK: mencakup CPMK1, CPMK2, dan integrasi komponen game.
- Tautan: [Kurikulum Program Studi Teknologi Permainan Polibatam (PDF)](https://www.polibatam.ac.id/wp-content/uploads/2024/06/Kurikulum-Prodi-TP.pdf)

### 5. Universitas Abdurrab — Pemrograman Game

- Institusi: Universitas Abdurrab
- Bentuk: deskripsi mata kuliah pada SPADA
- Kesesuaian: sangat tinggi
- Cakupan relevan: dasar pemrograman, struktur data, grafika, fisika permainan, AI untuk NPC, pencarian, desain interaksi, UI/UX, dan pengembangan lintas platform.
- Kaitan CPMK: substansinya mencakup keempat CPMK, terutama fisika sederhana dan AI NPC.
- Tautan: [Pemrograman Game Universitas Abdurrab](http://spada.univrab.ac.id/course/info.php?id=1303&lang=en)

### 6. Universitas Muhammadiyah Surakarta — Pemrograman Game

- Institusi: Universitas Muhammadiyah Surakarta (UMS)
- Bentuk: halaman resmi mata kuliah
- Kesesuaian: menengah–tinggi
- Cakupan relevan: konsep dan framework game, Game Design Document, level dan gameplay, cerita, karakter, serta pengembangan game untuk web dan perangkat bergerak.
- Kaitan CPMK: mendukung perancangan mekanik, pembangunan level, dan pengembangan proyek game.
- Tautan: [Pemrograman Game UMS](https://www.ums.ac.id/mata-kuliah/TIF3221362)

### 7. Universitas Muhammadiyah Surakarta — Praktikum Pemrograman Game

- Institusi: Universitas Muhammadiyah Surakarta (UMS)
- Bentuk: halaman resmi mata kuliah praktikum
- Kesesuaian: tinggi untuk kegiatan praktikum
- Cakupan relevan: animasi 2D dan 3D, Construct, Unity 3D, objek pemain dan musuh, scoring, plugin, serta pembuatan game sederhana.
- Kaitan CPMK: mendukung CPMK3 dan CPMK4.
- Tautan: [Praktikum Pemrograman Game UMS](https://www.ums.ac.id/mata-kuliah/TIF3221163)

### 8. Universitas Islam Negeri Maulana Malik Ibrahim Malang — Multimedia & Game Programming

- Institusi: UIN Maulana Malik Ibrahim Malang
- Program studi: Teknik Informatika
- Bentuk: halaman mata kuliah beserta materi per pertemuan
- Kesesuaian: menengah
- Cakupan relevan: paket materi Multimedia & Game Programming sebanyak 15 pertemuan yang dapat digunakan untuk membandingkan urutan bahan ajar.
- Kaitan CPMK: mendukung penyusunan distribusi topik per semester, terutama multimedia dan pemrograman game.
- Tautan: [Multimedia & Game Programming UIN Malang](https://informatika.uin-malang.ac.id/multimedia-game-programming/)

## Referensi Pendukung untuk Komponen Python/Pygame

### 9. STMIK Jakarta STI&K — Pemrograman Python

- Institusi: STMIK Jakarta STI&K
- Bentuk: RPS dalam PDF
- Fungsi: referensi untuk merumuskan sub-CPMK dan urutan kemampuan Python sebelum masuk ke Pygame.
- Cakupan relevan: sintaks Python, struktur kendali, perulangan, struktur data, fungsi, modul, exception, class, dan object.
- Tautan: [RPS Pemrograman Python STI&K (PDF)](https://jak-stik.ac.id/program-studi/rps/unduh/3%20RPS%20Pemrograman%20Phyton-SK.pdf)

### 10. Universitas Medan Area — Panduan Game 2D dengan Pygame

- Institusi: Universitas Medan Area
- Bentuk: panduan teknis resmi institusi
- Fungsi: referensi aktivitas praktikum CPMK1.
- Cakupan relevan: instalasi Pygame, pembuatan jendela, game loop, event handling, gerakan objek, grafik, musuh, collision, skor, dan efek suara.
- Tautan: [Panduan Membuat Game 2D dengan Pygame](https://p2dpm.uma.ac.id/2025/10/15/panduan-membuat-game-2d-sederhana-dengan-pygame/)

### 11. Universitas Brawijaya — Game Development with Python

- Institusi: Universitas Brawijaya
- Bentuk: artikel kegiatan dan materi pelatihan dalam PDF
- Fungsi: referensi penerapan Python/Pygame pada pembelajaran.
- Cakupan relevan: pengenalan Python dan Pygame, game 2D, mekanik permainan, pergerakan karakter, collision detection, dan sistem skor.
- Tautan: [Game Development with Python: Let's Build a Simple Game! (PDF)](https://gramaswara.ub.ac.id/index.php/gramaswara/article/download/185/128)

## Rekomendasi Pemanfaatan

- Gunakan RPS ITS sebagai pembanding utama untuk hubungan antara algoritma, Unity, dan AI game.
- Gunakan dokumen Polibatam dan deskripsi Universitas Abdurrab untuk melengkapi materi fisika, grafika, dan AI NPC.
- Gunakan RPS UNIMA dan UNESA sebagai pembanding CPMK penggunaan game engine, prototipe, aset, serta evaluasi.
- Gunakan RPS Pemrograman Python STI&K serta materi Pygame dari Universitas Medan Area dan Universitas Brawijaya untuk merancang tahapan praktikum CPMK1–CPMK2.
- Cantumkan tanggal akses ketika tautan-tautan ini dimasukkan ke dokumen RPS resmi karena isi halaman web dapat berubah.
