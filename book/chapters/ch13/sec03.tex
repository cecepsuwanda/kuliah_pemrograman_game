\section{Player Settings}

Sebelum build, kita harus memberi identitas pada game kita.

\begin{enumerate}
    \item Di window Build Settings, klik \textbf{Player Settings}.
    \item Isi \textbf{Company Name}: [Nama Anda].
    \item Isi \textbf{Product Name}: Space Survivor.
    \item \textbf{Resolution}: Untuk WebGL, atur Default Canvas Width/Height (misal 960 x 600).
    \item \textbf{Splash Image}: Jika Anda menggunakan Unity Personal, logo Unity akan muncul.
\end{enumerate}
