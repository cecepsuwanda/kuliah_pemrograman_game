\section{Pengaturan Build}

\begin{enumerate}
    \item Buka \textbf{File > Build Settings}.
    \item Pastikan Scene \texttt{MainMenu} ada di urutan 0, dan \texttt{Gameplay} di urutan 1.
    \item Pada bagian \textit{Platform}, pilih \textbf{WebGL}.
    \item Klik \textbf{Switch Platform} (ini mungkin memakan waktu beberapa menit).
    \item Jika ada peringatan "Color Space", biasanya Unity meminta untuk mengubah ke Gamma Space (untuk kompabilitas WebGL 1.0) atau tetap Linear (untuk WebGL 2.0). Pilih yang disarankan pemain.
\end{enumerate}
