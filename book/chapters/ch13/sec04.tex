\section{Build Process dan Troubleshooting}

\begin{learningoutcomes}
\item Memahami build process
\item Mengatasi build errors
\item Testing build
\item Memahami build logs
\end{learningoutcomes}

\subsection{Build Process}

\begin{enumerate}
\item Prepare assets
\item Compile scripts
\item Process assets
\item Build executable
\item Package for distribution
\end{enumerate}

\subsection{Common Build Errors}

\begin{itemize}
\item \textbf{Missing References}: Scene atau asset tidak ditemukan
\item \textbf{Script Errors}: Compile errors
\item \textbf{Platform Modules}: Module tidak terinstall
\item \textbf{License Issues}: Platform license tidak valid
\end{itemize}

\subsection{Troubleshooting}

\begin{itemize}
\item Check Console untuk errors
\item Verify semua scenes di Build Settings
\item Ensure platform modules terinstall
\item Check Player Settings
\item Review build logs
\end{itemize}

\begin{catatan}
Build errors biasanya jelas di Console. Fix errors sebelum build. Test build di target device untuk memastikan berfungsi.
\end{catatan}
