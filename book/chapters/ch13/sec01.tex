\section{Memilih Platform Target}

Selamat! Game \textbf{Space Survivor} Anda sudah jadi. Tapi saat ini game tersebut hanya bisa dimainkan di Unity Editor. Kita harus mengekspornya.

Kita punya dua pilihan populer:
\begin{enumerate}
    \item \textbf{PC (Windows/Mac/Linux)}: Performa terbaik, file berupa .exe. Cocok untuk Steam.
    \item \textbf{WebGL}: Game berjalan di Browser. Cocok untuk diupload ke itch.io agar teman-teman bisa main tanpa download.
\end{enumerate}

Untuk latihan ini, kita akan mencoba \textbf{WebGL} agar mudah dibagikan.
