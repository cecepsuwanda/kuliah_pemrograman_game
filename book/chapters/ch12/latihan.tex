\section{Latihan: Optimasi Total}

\begin{enumerate}
    \item \textbf{Bullet Pool}: Implementasikan Object Pool untuk peluru player. Cek Hierarchy saat main, tidak boleh ada peluru baru yang muncul (Clone) terus menerus. Jumlah anak BulletPool harus tetap (misal 20).
    \item \textbf{Asteroid Pool}: (Tantangan) Asteroid juga muncul terus menerus. Buatlah \texttt{AsteroidPool} agar performa game makin kencang.
    \item \textbf{Enemy Ship Pool}: (Tantangan Ekstrem) Sama seperti asteroid, tapi untuk musuh pintar.
\end{enumerate}

Dengan optimasi ini, Space Survivor siap dimainkan di HP kentang sekalipun! Langkah terakhir adalah \textbf{Build} game ini agar bisa dibagikan ke teman-teman.
