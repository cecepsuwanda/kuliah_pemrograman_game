\chapter{Konsep Dasar Game Development}

\section{Deskripsi Bab}

Bab ini membahas konsep fundamental dalam pengembangan game, termasuk definisi game, elemen-elemen pembentuk game, berbagai genre game, dokumen desain game (GDD), lifecycle pengembangan game, dan struktur tim pengembangan. Pemahaman terhadap konsep-konsep ini merupakan fondasi penting sebelum mempelajari aspek teknis pengembangan game menggunakan Unity Engine.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK1.1}: Menganalisis definisi game dan elemen-elemen pembentuknya (mechanics, dynamics, aesthetics)
\item \textbf{Sub-CPMK1.2}: Mengidentifikasi berbagai genre game dan karakteristiknya
\item \textbf{Sub-CPMK1.3}: Menyusun Game Design Document (GDD) untuk konsep game
\item \textbf{Sub-CPMK1.4}: Menjelaskan lifecycle pengembangan game dari pre-production hingga post-production
\item \textbf{Sub-CPMK1.5}: Memahami peran dan tanggung jawab dalam tim pengembangan game
\end{itemize}

\section{Ringkasan Teori Inti}

\begin{itemize}
\item Game adalah aktivitas terstruktur dengan tujuan, aturan, dan umpan balik
\item Elemen game terdiri dari Mechanics (aturan), Dynamics (perilaku), dan Aesthetics (pengalaman)
\item Genre game menentukan kategori dan karakteristik gameplay
\item GDD adalah dokumen penting yang menjelaskan konsep game secara detail
\item Lifecycle pengembangan game meliputi tiga tahap utama: pre-production, production, dan post-production
\item Tim pengembangan game terdiri dari berbagai peran spesialis
\end{itemize}
