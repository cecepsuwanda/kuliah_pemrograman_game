\chapter{Physics, Collision, dan Rigidbody}

\section{Deskripsi Bab}

Bab ini membahas sistem fisika Unity termasuk Rigidbody, Collider, collision detection, Physics Material, dan Raycast. Mahasiswa akan mempelajari bagaimana mengimplementasikan simulasi fisika dalam game untuk gerak, gravitasi, tumbukan, dan interaksi fisik.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK6.1}: Menggunakan Rigidbody untuk simulasi fisika
\item \textbf{Sub-CPMK6.2}: Mengkonfigurasi berbagai jenis Collider
\item \textbf{Sub-CPMK6.3}: Mengimplementasikan collision detection
\item \textbf{Sub-CPMK6.4}: Menggunakan Physics Material untuk friction dan bounce
\item \textbf{Sub-CPMK6.5}: Menggunakan Raycast untuk deteksi
\item \textbf{Sub-CPMK6.6}: Mengimplementasikan trigger untuk interaksi
\end{itemize}
