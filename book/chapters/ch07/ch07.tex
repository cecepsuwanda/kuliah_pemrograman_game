\section{Deskripsi Bab}

Bab ini membahas sistem animasi Unity menggunakan Animator Controller. Mahasiswa akan mempelajari state machine, transitions, parameters, blend trees, dan integrasi animasi dengan gameplay melalui script.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK7.1}: Membuat Animator Controller
\item \textbf{Sub-CPMK7.2}: Mengkonfigurasi animation states
\item \textbf{Sub-CPMK7.3}: Membuat transitions antar states
\item \textbf{Sub-CPMK7.4}: Menggunakan parameters untuk kontrol animasi
\item \textbf{Sub-CPMK7.5}: Mengimplementasikan blend trees
\end{itemize}
