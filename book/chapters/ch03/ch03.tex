\chapter{Dasar Pemrograman C\# untuk Unity}

\section{Deskripsi Bab}

Bab ini membahas dasar-dasar pemrograman C\# dalam konteks Unity game development. Mahasiswa akan mempelajari struktur skrip Unity menggunakan MonoBehaviour, lifecycle functions, variabel dan tipe data, kontrol alur program, konsep object-oriented programming, coroutine, dan event system. Pemahaman terhadap konsep-konsep ini merupakan fondasi penting untuk mengembangkan gameplay mechanics dalam Unity.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK3.1}: Membuat skrip C\# menggunakan MonoBehaviour
\item \textbf{Sub-CPMK3.2}: Memahami dan menggunakan lifecycle functions (Start, Update, Awake, dll)
\item \textbf{Sub-CPMK3.3}: Menggunakan variabel dan tipe data Unity (Vector3, Quaternion, dll)
\item \textbf{Sub-CPMK3.4}: Menerapkan kontrol alur program (if-else, loop, switch)
\item \textbf{Sub-CPMK3.5}: Memahami konsep OOP dalam Unity
\item \textbf{Sub-CPMK3.6}: Menggunakan coroutine untuk asynchronous operations
\item \textbf{Sub-CPMK3.7}: Mengimplementasikan event dan delegate
\end{itemize}
