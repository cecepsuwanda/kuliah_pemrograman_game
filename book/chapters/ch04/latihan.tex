\section{Latihan: Setup Project Space Survivor}

Untuk memastikan Anda siap melanjutkan ke tahap pemrograman, selesaikan langkah-langkah berikut:

\begin{enumerate}
    \item \textbf{Setup Project}: Pastikan Anda telah membuat project ``Space Survivor'' dengan struktur folder yang benar (Scripts, Prefabs, Scenes, Sprites).
    \item \textbf{Player}: Anda harus memiliki GameObject \texttt{Player} di scene \texttt{Gameplay} yang memiliki komponen \texttt{Rigidbody 2D} (Gravity 0) dan \texttt{Collider}.
    \item \textbf{Prefabs}: Anda wajib memiliki file \texttt{Bullet.prefab} dan \texttt{Asteroid.prefab} di dalam folder Prefabs.
    \item \textbf{Scenes}: Pastikan ada dua file scene (\texttt{MainMenu.unity} dan \texttt{Gameplay.unity}).
\end{enumerate}

Jika semua sudah siap, kita akan mulai memprogram pergerakan pesawat di \textbf{Bab 5}.
