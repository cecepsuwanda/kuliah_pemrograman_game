\section{Mengelola Scene}

Game kita membutuhkan setidaknya dua scene: \textbf{MainMenu} dan \textbf{Gameplay}.

\subsection{Menyimpan Scene Gameplay}

\begin{enumerate}
    \item Tekan \texttt{Ctrl + S} (Save).
    \item Simpan scene saat ini di folder \texttt{Scenes} dengan nama \texttt{Gameplay}.
\end{enumerate}

\subsection{Membuat Scene Main Menu}

\begin{enumerate}
    \item Klik \texttt{File > New Scene}.
    \item Pilih \textbf{Basic (2D)}.
    \item Simpan scene ini dengan nama \texttt{MainMenu}.
    \item Kosongkan isinya untuk saat ini (kita akan hias di Bab UI).
\end{enumerate}

\subsection{Build Settings}

Agar Unity mengenali kedua scene ini:

\begin{enumerate}
    \item Buka \texttt{File > Build Settings}.
    \item Tarik kedua scene (\texttt{MainMenu} dan \texttt{Gameplay}) ke dalam daftar \textbf{Scenes In Build}.
    \item Pastikan \texttt{MainMenu} ada di urutan paling atas (index 0).
\end{enumerate}
