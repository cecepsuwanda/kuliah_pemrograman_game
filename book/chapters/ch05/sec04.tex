\section{Kamera Mengikuti Pemain}

Agar pemain tidak keluar layar, kamera harus mengikuti pesawat. 

\subsection{Script CameraFollow}
Buat script \texttt{CameraFollow.cs} dan pasang pada \textbf{Main Camera}:

\begin{lstlisting}[language={[Sharp]C}]
public class CameraFollow : MonoBehaviour
{
    public Transform target;
    public Vector3 offset = new Vector3(0, 0, -10);
    public float smoothSpeed = 0.125f;

    void LateUpdate()
    {
        if (target != null)
        {
            Vector3 desiredPosition = target.position + offset;
            Vector3 smoothedPosition = Vector3.Lerp(transform.position, desiredPosition, smoothSpeed);
            transform.position = smoothedPosition;
        }
    }
}
\end{lstlisting}

\begin{tips}
Jangan lupa drag object \texttt{Player} ke slot \texttt{Target} pada komponen Camera Follow di Inspector Main Camera.
\end{tips}
