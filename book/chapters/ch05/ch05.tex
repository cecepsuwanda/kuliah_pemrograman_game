\chapter{Input System dan Player Controller}

\section{Deskripsi Bab}

Bab ini membahas sistem input Unity dan implementasi player controller. Mahasiswa akan mempelajari Unity Input System (legacy dan new), handling input keyboard/mouse, touch untuk mobile, gamepad, implementasi player movement, dan camera control.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK5.1}: Menggunakan Unity Input System
\item \textbf{Sub-CPMK5.2}: Mengimplementasikan keyboard dan mouse input
\item \textbf{Sub-CPMK5.3}: Menggunakan touch input untuk mobile
\item \textbf{Sub-CPMK5.4}: Mengimplementasikan gamepad/controller input
\item \textbf{Sub-CPMK5.5}: Membuat player movement yang responsif
\item \textbf{Sub-CPMK5.6}: Mengatur camera follow dan control
\end{itemize}
