\section{Konsep Input di Unity}

Unity menyediakan cara mudah untuk membaca input keyboard, mouse, atau joystick.

\subsection{Input Manager (Legacy)}

Untuk game ini, kita akan menggunakan sistem input standar yang sederhana.
Cek pengaturan input di: \textbf{Edit > Project Settings > Input Manager}.

Perhatikan Axes berikut:
\begin{itemize}
    \item \textbf{Horizontal} (A/D, Arrows): Gerakan Kiri/Kanan
    \item \textbf{Vertical} (W/S, Arrows): Gerakan Maju/Mundur
    \item \textbf{Fire1} (Ctrl, Mouse0): Menembak/Aksi Utama
    \item \textbf{Jump} (Space): Melompat
    \item \textbf{Mouse X/Y}: Rotasi Kamera
\end{itemize}

Kita akan menggunakan axis \textbf{Horizontal} dan \textbf{Vertical} untuk menggerakkan pesawat.
