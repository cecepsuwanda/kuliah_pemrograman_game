\chapter{Pengenalan Unity Engine}

\section{Deskripsi Bab}

Bab ini memperkenalkan Unity Engine sebagai platform pengembangan game yang powerful dan populer. Mahasiswa akan mempelajari sejarah Unity, proses instalasi dan setup, interface Unity Editor, workflow pengembangan game, serta penggunaan Unity Asset Store dan package management. Pemahaman terhadap Unity Editor merupakan fondasi penting sebelum mempelajari aspek teknis pengembangan game.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK2.1}: Menjelaskan sejarah dan keunggulan Unity Engine
\item \textbf{Sub-CPMK2.2}: Menginstal dan mengkonfigurasi Unity Hub dan Unity Editor
\item \textbf{Sub-CPMK2.3}: Mengoperasikan Unity Editor interface dengan mahir
\item \textbf{Sub-CPMK2.4}: Memahami workflow pengembangan game di Unity
\item \textbf{Sub-CPMK2.5}: Menggunakan Unity Asset Store dan package management
\end{itemize}
