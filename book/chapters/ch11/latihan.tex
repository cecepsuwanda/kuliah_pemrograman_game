\section{Latihan: Dangerous Space}

\begin{enumerate}
    \item \textbf{Enemy Spawner Upgrade}: Modifikasi script \texttt{EnemySpawner} agar bisa memunculkan dua jenis musuh: \texttt{Asteroid} (Diam/Jatuh) dan \texttt{EnemyShip} (Mengejar). Gunakan Array \texttt{GameObject[]} untuk menyimpan variasi prefab.
    \item \textbf{Shooting Enemy}: (Tantangan) Tambahkan kemampuan menembak pada Musuh jika jarak ke pemain sudah dekat.
    \item \textbf{Variasi Kecepatan}: Buat agar EnemyShip memiliki kecepatan acak agar tidak menumpuk.
\end{enumerate}

Dengan adanya musuh pintar, game ini makin menantang. Tapi tunggu, jika kita main lama-lama, game bisa lag. Kenapa? Temukan jawabannya di \textbf{Bab 12: Optimization}.
