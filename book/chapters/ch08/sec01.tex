\section{UI di Space Survivor}

Sebagian besar game membutuhkan antarmuka untuk memberikan informasi kepada pemain. Di \textbf{Space Survivor}, kita membutuhkan:
\begin{itemize}
    \item \textbf{HUD (Heads-Up Display)}: Menampilkan Skor saat bermain.
    \item \textbf{Menu System}: Tombol \textbf{Play} untuk mulai permainan.
    \item \textbf{Game Over Screen}: Menampilkan tombol \textbf{Restart} saat pemain mati.
\end{itemize}

\subsection{Canvas}
Canvas adalah area kerja untuk semua elemen UI.
\begin{enumerate}
    \item Klik kanan Hierarchy > \textbf{UI} > \textbf{Canvas}.
    \item Penting: Ubah \textbf{Canvas Scaler (Script)} > \textbf{UI Scale Mode} menjadi \texttt{Scale With Screen Size}. Ini agar UI tidak berantakan di layar HP/Monitor yang berbeda resolusi.
\end{enumerate}
