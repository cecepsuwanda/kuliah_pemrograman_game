\chapter{UI/UX Game}

\section{Deskripsi Bab}

Bab ini membahas sistem UI Unity. 
Dalam \textbf{Space Survivor}, UI sangat vital untuk memberi tahu pemain berapa skor mereka dan memfasilitasi alur permainan dari Menu Utama ke Gameplay. Kita akan menggunakan Canvas, TextMeshPro, dan Button.

\section{Sub-CPMK Bab}

Setelah mempelajari bab ini, mahasiswa diharapkan mampu:
\begin{itemize}
\item \textbf{Sub-CPMK8.1}: Menggunakan Canvas dan Canvas Scaler
\item \textbf{Sub-CPMK8.2}: Mengimplementasikan UI components (Button, Text, Image, Slider)
\item \textbf{Sub-CPMK8.3}: Menggunakan Event System untuk UI interactions
\item \textbf{Sub-CPMK8.4}: Merancang dan mengimplementasikan HUD
\item \textbf{Sub-CPMK8.5}: Membuat sistem menu (Main menu, Pause menu)
\end{itemize}
