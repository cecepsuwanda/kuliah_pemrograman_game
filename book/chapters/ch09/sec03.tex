\section{Background Music (BGM)}

Musik latar membangun suasana.

\subsection{GameObject BGM}
\begin{enumerate}
    \item Buat GameObject kosong baru bernama \texttt{AudioManager}.
    \item Tambahkan Component \textbf{Audio Source}.
    \item Drag file musik Anda ke slot \texttt{AudioClip}.
    \item Pastikan \texttt{Play On Awake} \textbf{DICENTANG}.
    \item Pastikan \texttt{Loop} \textbf{DICENTANG} (agar musik berulang terus).
    \item Atur \texttt{Volume} ke level yang nyaman (misal 0.5) agar tidak menutupi suara efek.
\end{enumerate}

Sekarang, saat game dimainkan, musik akan otomatis mengalun.
