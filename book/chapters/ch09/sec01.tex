\section{Audio di Space Survivor}

Game diam itu membosankan. Di \textbf{Space Survivor}, kita perlu menambahkan tiga jenis suara:
\begin{itemize}
    \item \textbf{Sound Effects (SFX)}: Suara tembakan dan ledakan.
    \item \textbf{Background Music (BGM)}: Musik latar yang terus berulang.
    \item \textbf{UI Sound}: Suara klik tombol (opsional).
\end{itemize}

Pastikan Anda sudah mengimpor file audio (format .mp3 atau .wav) ke dalam folder \texttt{Audio}.

\begin{itemize}
    \item \textbf{Audio Clip}: File suara mentah (.mp3, .wav)
    \item \textbf{Audio Source}: Pemancar suara (Speaker) yang dipasang di GameObject
    \item \textbf{Audio Listener}: Pendengar suara (Telinga), biasanya di Main Camera
\end{itemize}
