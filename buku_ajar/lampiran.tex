\section*{Lampiran C: Glosarium Istilah Game Development}

\begin{itemize}
  \item \textbf{Game Engine}: Perangkat lunak yang menyediakan kerangka untuk membuat game, termasuk rendering, physics, audio, dan scripting.
  \item \textbf{GameObject}: Unit dasar dalam Unity yang mewakili karakter, objek, atau elemen dalam scene.
  \item \textbf{Component}: Modul yang menambahkan perilaku atau properti pada GameObject (Transform, Rigidbody, Collider, Script).
  \item \textbf{Transform}: Component yang menyimpan posisi, rotasi, dan skala GameObject.
  \item \textbf{Rigidbody}: Component yang mengaktifkan simulasi fisika pada GameObject.
  \item \textbf{Collider}: Component yang mendeteksi tabrakan antara objek.
  \item \textbf{Trigger}: Collider yang mendeteksi overlap tanpa respons fisik.
  \item \textbf{MonoBehaviour}: Base class untuk semua script Unity yang melekat pada GameObject.
  \item \textbf{Prefab}: Template GameObject yang dapat diinstansiasi ulang.
  \item \textbf{Scene}: Kontainer untuk semua GameObject dalam level tertentu.
  \item \textbf{Canvas}: Elemen UI untuk menampilkan teks, tombol, dan elemen antarmuka.
  \item \textbf{Game Loop}: Siklus utama game: Input $\rightarrow$ Update $\rightarrow$ Render.
\end{itemize}
