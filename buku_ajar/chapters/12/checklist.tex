\bagian{Checklist Pencapaian Kompetensi}

Bab ini menuntaskan \SUBCPMK{3.1}, yaitu bab pertama pada \CPMK{3}. Centang
setiap butir berikut hanya apabila Anda benar-benar telah melakukannya atau
dapat menjelaskannya.

\begin{checklistbox}
\begin{checklist}
  \item Saya dapat menjelaskan pekerjaan apa saja yang diambil alih mesin
        permainan, dan apa akibatnya bagi cara saya bekerja.
  \item {\bfseries (Indikator a)} Saya dapat mengoperasikan
        \istilah{Hierarchy}, \istilah{Inspector}, \istilah{Project window}, dan
        \istilah{Scene}.
  \item Saya dapat menjelaskan perbedaan \istilah{Hierarchy} dan
        \istilah{Project window}.
  \item Saya dapat menjelaskan kegunaan panel \istilah{Game} dan
        \istilah{Console}.
  \item {\bfseries (Indikator b)} Saya telah memasang Unity LTS beserta modul
        dukungan 2D, dan mencatat nomor versinya.
  \item Saya telah membuat \istilah{project} 2D dan menyusun sebuah
        \istilah{scene} berisi kamera, pencahayaan, dan sekurang-kurangnya
        tiga objek primitif.
  \item Saya telah menyimpan \istilah{scene} itu, dan memeriksa berkas apa saja
        yang muncul pada folder \code{Assets}.
  \item Saya telah menulis dan menempelkan sebuah skrip C\# pada sebuah benda,
        lalu menjalankan scene-nya.
  \item Saya dapat menjelaskan kapan fungsi \code{Awake}, \code{Start},
        \code{Update}, \code{FixedUpdate}, dan \code{OnDisable} dipanggil.
  \item Saya dapat menjelaskan mengapa selang waktu tidak perlu diukur sendiri
        pada Unity, dan menyebutkan nama nilainya.
  \item {\bfseries (Indikator c)} Saya telah menyusun tabel padanan konsep
        Pygame dan Unity dengan kata-kata sendiri.
  \item Saya dapat menyebutkan sekurang-kurangnya empat konsep yang tetap sama
        persis pada kedua perkakas.
  \item Berkas \code{.gitignore} pada project Unity saya mendaftarkan folder
        \code{Library}, \code{Temp}, \code{Obj}, dan \code{Build}.
  \item Catatan praktikum saya memuat tangkapan layar scene buatan sendiri.
\end{checklist}
\end{checklistbox}
