\begin{tujuanbox}
Bab ini mengubah kerangka teori pada Bab~II menjadi perkakas yang bekerja di
komputer Anda. Setelah menuntaskan bab ini, Anda mampu:
\begin{enumerate}
  \item menyiapkan lingkungan kerja Python untuk pemrograman permainan dan
        memeriksa kesiapannya secara mandiri;
  \item memasang Pygame serta menjelaskan kedudukannya di antara program Anda
        dan perangkat keras;
  \item menyusun struktur folder proyek dan mengelola pekerjaan dengan
        pengendali versi Git;
  \item menulis, menjalankan, dan mengubah program Pygame pertama yang
        membuka jendela serta menampilkan teks;
  \item membaca pesan kesalahan Python dan menentukan penyebabnya dengan
        memanfaatkan informasi pada pesan tersebut;
  \item membedakan peringatan (\istilah{warning}) dari kesalahan
        (\istilah{error}) dan bersikap tepat terhadap keduanya.
\end{enumerate}
\end{tujuanbox}
