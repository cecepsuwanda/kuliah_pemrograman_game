\section{Animator Controller dan Animation Clip}

\begin{learningoutcomes}
\item Memahami Animator Controller dan Animation Clip
\item Membuat animasi sederhana
\item Mengimplementasikan animasi explosion
\end{learningoutcomes}

\subsection{Konsep Animasi Unity}

Animator Controller: mengatur kapan animasi dimainkan. Animation Clip: data gerakan frame-by-frame. Animator component menghubungkan GameObject ke Animator Controller.

\subsection{Membuat Explosion Animation}

Buat sprite sheet atau sequence untuk ledakan. Buat Animation Clip. Buat Animator Controller dengan state Explode. Trigger animasi saat asteroid hancur. Destroy GameObject setelah animasi selesai.
