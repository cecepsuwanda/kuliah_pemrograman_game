\section{Tujuan Buku Ajar}

Buku ajar ini dirancang sebagai panduan komprehensif untuk menguasai Pemrograman Game menggunakan Unity Engine dan bahasa C\# \cite{UnityManual2024}. Fokus utama buku ini adalah pada implementasi game development dari konsep dasar hingga deployment ke berbagai platform. Tujuan spesifik buku ini adalah:

\begin{enumerate}
  \item Memberikan pemahaman mendalam tentang konsep game development (mechanics, dynamics, aesthetics, GDD, lifecycle)
  \item Mengembangkan kemampuan menggunakan Unity Engine dan bahasa pemrograman C\# untuk game
  \item Membangun keterampilan implementasi fitur game (input, physics, animasi, UI, audio, AI)
  \item Menumbuhkan kemampuan optimasi, debugging, dan deployment game
  \item Memfasilitasi pencapaian CPL dan CPMK yang telah ditetapkan
\end{enumerate}

Setelah mempelajari buku ini secara menyeluruh, mahasiswa diharapkan mampu:
\begin{itemize}
  \item Menjelaskan konsep fundamental game development (MDA framework, genre, GDD)
  \item Mengoperasikan Unity Editor dan membuat project game
  \item Mengimplementasikan gameplay menggunakan C\# dan komponen Unity
  \item Membuat game dengan fitur lengkap (player controller, physics, UI, audio)
  \item Mengoptimasi dan mendeploy game ke berbagai platform
\end{itemize}
