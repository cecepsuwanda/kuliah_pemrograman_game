\section{Deployment}

Setelah build, folder output berisi:
\begin{itemize}
  \item \texttt{RollABall.exe} (Windows) atau \texttt{RollABall.app} (Mac): executable
  \item \texttt{RollABall\_Data}: folder aset, library, DLL. Wajib ada di folder yang sama dengan .exe
\end{itemize}

\textbf{Distribusi}: Zip seluruh folder dan kirim. Player tidak perlu install Unity. Jalankan .exe untuk bermain. Sub-CPMK 5.2 tercapai: build game untuk platform target.
