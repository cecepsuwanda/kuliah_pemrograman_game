\section{Build Settings dan Platform}

\begin{learningoutcomes}
\item Mengkonfigurasi Build Settings
\item Build untuk Windows/PC
\item Build untuk Android/WebGL

\subsection{Build Settings}

File $\rightarrow$ Build Settings. Pilih platform: PC/Mac/Linux, Android, iOS, WebGL. Add build modules jika perlu. Switch Platform. Build untuk executable. Build and Run untuk test. Scenes In Build: urutan scene.

\subsection{Platform-Specific}

Resolution setting. Quality settings per platform. Input (touch vs keyboard). Icon, splash screen. Player settings untuk nama app, package name (Android).
