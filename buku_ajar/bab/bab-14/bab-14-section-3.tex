\section{Persiapan Release}

\begin{learningoutcomes}
\item Checklist sebelum release
\item Quality assurance
\item Testing multiplatform
\end{learningoutcomes}

\subsection{Checklist}

Semua scene di Build. Tidak ada error di Console. Test full flow. Performance acceptable. Audio balance. UI readable di berbagai resolusi. Save/Load works.

\subsection{Testing}

Test di target device. Different resolutions. Input methods. Memory leaks. Edge cases. Beta testing dengan user.
