\section{Deployment dan Distribusi}

\begin{learningoutcomes}
\item Mempersiapkan build untuk distribusi
\item Memahami platform store (Google Play, itch.io)
\item Version control untuk project
\end{learningoutcomes}

\subsection{Deployment}

Build development vs release. Development: debugging. Release: optimize, strip debug. Signing (Android keystore). Compression. Addressables untuk large projects.

\subsection{Distribusi}

itch.io: upload zip/build. Google Play: AAB format, store listing. Steam: depot upload. Version number, release notes. Cloud save, analytics (opsional).
