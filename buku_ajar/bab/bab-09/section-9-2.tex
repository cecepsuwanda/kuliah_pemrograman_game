\section{Menu System dan Game Over}

\begin{learningoutcomes}
\item Membuat Main Menu dengan tombol Play
\item Membuat Game Over screen
\item Mengelola scene loading
\end{learningoutcomes}

\subsection{Main Menu}

Canvas dengan Button ``Play''. OnClick $\rightarrow$ SceneManager.LoadScene("Gameplay"). Scene Management: using UnityEngine.SceneManagement.

\subsection{Game Over Screen}

Panel Game Over (awal disabled). Saat player mati: panel.SetActive(true). Button Restart: SceneManager.LoadScene(SceneManager.GetActiveScene().buildIndex). Button Main Menu: LoadScene(0).
