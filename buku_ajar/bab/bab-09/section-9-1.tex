\section{Canvas dan Elemen UI}

\begin{learningoutcomes}
\item Memahami Canvas dan layout UI
\item Membuat HUD (Score, Health)
\item Mengatur Canvas Scaler
\end{learningoutcomes}

\subsection{Canvas}

Canvas adalah area untuk semua elemen UI. UI $\rightarrow$ Canvas. Canvas Scaler: Scale With Screen Size agar UI adaptif di berbagai resolusi. Reference Resolution 1920x1080, Match Width/Height.

\subsection{Elemen UI}

Text (TMPro atau Legacy): skor, health. Image: icon, panel. Button: Play, Restart. Layout: Horizontal/Vertical Layout Group untuk auto-arrange.
