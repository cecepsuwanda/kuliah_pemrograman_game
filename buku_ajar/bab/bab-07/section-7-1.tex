\section{Physics, Rigidbody, dan Collider}

\begin{learningoutcomes}
\item Memahami konsep fisika Unity
\item Menggunakan Rigidbody 2D/3D
\item Mengkonfigurasi Collider untuk collision detection
\end{learningoutcomes}

\subsection{Rigidbody vs Collider}

Agar collision terjadi: minimal satu objek punya Rigidbody, kedua punya Collider. Rigidbody: fisika (gravity, velocity). Collider: bentuk untuk deteksi tabrakan. Tipe Collider 2D: Box, Circle, Capsule, Polygon.

\subsection{Trigger vs Collision}

Is Trigger = true: OnTriggerEnter/Exit/Stay (tidak memblok fisik). Is Trigger = false: OnCollisionEnter (fisik collision). Peluru: Trigger. Player-Asteroid: Collision (Game Over).
