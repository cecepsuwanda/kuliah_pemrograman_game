\section{Profiler dan Optimasi}

\begin{learningoutcomes}
\item Menggunakan Unity Profiler
\item Mengidentifikasi bottleneck (CPU, GPU, memory)
\item Menerapkan Object Pooling
\end{learningoutcomes}

\subsection{Unity Profiler}

Window $\rightarrow$ Analysis $\rightarrow$ Profiler. CPU: script, physics. GPU: rendering. Memory: allocations. Play mode + Profiler untuk analisis runtime. Cari spikes dan penyebab.

\subsection{Object Pooling}

Hindari Instantiate/Destroy berulang (costly). Buat pool: list GameObjects. Get: aktifkan dari pool. Return: nonaktifkan, kembalikan ke pool. Untuk bullet, asteroid, enemy.
