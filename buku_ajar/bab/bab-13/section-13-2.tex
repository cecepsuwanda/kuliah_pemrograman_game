\section{Debugging dan Best Practices}

\begin{learningoutcomes}
\item Menggunakan Debug.Log dan breakpoint
\item Memahami common errors Unity
\item Menerapkan best practices
\end{learningoutcomes}

\subsection{Debugging}

Debug.Log, Debug.LogWarning, Debug.LogError. Console untuk trace. Breakpoint di Visual Studio. Debug.DrawLine untuk visualize. Assert untuk validasi.

\subsection{Best Practices}

Cache GetComponent (jangan di Update). Gunakan CompareTag bukan string. Avoid Find pada runtime. Null check. Layer untuk physics. Disable unnecessary components.
