\section{Visual Polish}

Beberapa peningkatan visual untuk game terlihat lebih menarik:

\begin{itemize}
  \item \textbf{Rotasi collectible}: Buat script untuk collectible, di Update: \texttt{transform.Rotate(0, 50 * Time.deltaTime, 0)} agar berputar
  \item \textbf{Particle effect}: GameObject $\rightarrow$ Effects $\rightarrow$ Particle System. Trigger saat collect
  \item \textbf{Material emission}: Di material, enable Emission untuk glow
  \item \textbf{Lighting}: Atur Directional Light rotation, shadow strength
\end{itemize}
