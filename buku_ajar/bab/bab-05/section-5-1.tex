\section{GameObject, Transform, dan Hierarchy}

\begin{learningoutcomes}
\item Memahami konsep GameObject dan Hierarchy
\item Menggunakan Transform component untuk posisi, rotasi, skala
\item Memahami konsep parent-child
\end{learningoutcomes}

\subsection{GameObject}

\begin{definisi}[GameObject]
GameObject adalah objek dasar dalam Unity yang dapat ditempatkan di scene dan memiliki komponen \cite{UnityManual2024}.
\end{definisi}

Setiap GameObject memiliki komponen Transform (posisi, rotasi, skala). Buat GameObject: Hierarchy $\rightarrow$ klik kanan $\rightarrow$ 2D Object $\rightarrow$ Sprites.

\subsection{Transform Component}

Transform menyimpan Position (x, y, z), Rotation, dan Scale. Parent-child: saat parent bergerak, child ikut bergerak. Gunakan Empty GameObject sebagai organizer.

\subsection{Setup Project Space Survivor}

Buat project 2D, struktur folder: Sprites, Scripts, Prefabs, Scenes, Audio. Buat Player dari Sprite Triangle, atur Scale, tambahkan child Engine.
