\begin{aktivitas}
  \item \textbf{Setup Project}: Install Unity Hub dan Unity Editor (versi LTS), buat project baru dengan template 3D, eksplorasi struktur folder project.
  
  \item \textbf{Eksplorasi Interface}: Buka semua panel utama Unity Editor, coba setiap tool di toolbar, buat beberapa GameObject dan eksplorasi Hierarchy serta Inspector.
  
  \item \textbf{Setup Workflow}: Buat struktur folder yang terorganisir, buat scene baru dan setup basic hierarchy, buat beberapa GameObject dan convert ke Prefab.
\end{aktivitas}

    \item Package Manager
  \end{enumerate}

  \begin{enumerate}

    \item Project
    \item Hierarchy

\begin{rangkuman}
Bab ini membahas pengenalan Unity Engine termasuk sejarah, instalasi, interface editor, workflow, dan package management.

\textbf{Poin Kunci:}
\begin{itemize}
  \item Unity adalah game engine cross-platform yang powerful dan user-friendly
  \item Unity Hub untuk mengelola versi dan project
  \item Panel utama: Scene, Game, Hierarchy, Inspector, Project, Console
  \item Workflow: Planning, Asset Creation, Scene Setup, Scripting, Testing, Build
  \item Scene dan Prefab adalah konsep fundamental Unity
\end{itemize}
\end{rangkuman}
