\section{State Machine AI dan NavMesh}

\begin{learningoutcomes}
\item Menerapkan State Machine untuk AI
\item Menggunakan NavMesh Agent (3D)
\item Mengimplementasikan detect/attack pattern
\end{learningoutcomes}

\subsection{State Machine AI}

State: Idle, Patrol, Chase, Attack. Transition: player in range $\rightarrow$ Chase. In attack range $\rightarrow$ Attack. Lost player $\rightarrow$ Patrol. Implement dengan enum dan switch.

\subsection{NavMesh (3D)}

Bake NavMesh di scene. NavMeshAgent component. SetDestination(player.position). Pathfinding otomatis. Untuk 2D: implementasi manual atau package 2D pathfinding.
