\section{Peta Konsep dan Alur Pembelajaran}

Buku ini menyajikan teori pengembangan game 3D dengan ``Roll a Ball'' \cite{unityRollABall} sebagai contoh konseptual. Konsep-konsep yang dipelajari terhubung dalam alur pengembangan game:

\begin{enumerate}
  \item \textbf{Setup}: Project, scene, play area (Ground, primitives)
  \item \textbf{Player}: Rigidbody, input keyboard, gerakan dengan \method{AddForce}
  \item \textbf{Camera}: Pola camera follow agar kamera mengikuti objek
  \item \textbf{Collectibles}: Collision detection dengan OnTriggerEnter
  \item \textbf{UI}: Menampilkan skor, kondisi menang
  \item \textbf{Polish}: Audio, prefabs untuk pengelolaan objek
  \item \textbf{Build}: Export game untuk platform target (Windows, dll.)
\end{enumerate}

\begin{konsep}
Setiap bab membahas satu topik teori. Mahasiswa mempelajari konsep dan melihat integrasinya dalam game lengkap. Untuk praktek implementasi, Unity Learn tersedia: \url{https://learn.unity.com/course/roll-a-ball}.
\end{konsep}
