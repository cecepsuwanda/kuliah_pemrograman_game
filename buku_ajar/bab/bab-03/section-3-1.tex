\section{Unity Editor dan Jendela Utama}

Unity Editor merupakan lingkungan pengembangan terpadu (IDE) untuk membuat game \cite{unityManual}. Setelah membuka project, Anda akan melihat antarmuka dengan beberapa jendela. Layout default (Default Layout) menampilkan jendela utama di posisi yang logis. Anda dapat mengubah layout dari menu \texttt{Window $\rightarrow$ Layouts}.

\subsection{Hierarchy}

Hierarchy menampilkan semua GameObject dalam scene aktif. GameObject baru dapat dibuat melalui menu konteks (klik kanan): \texttt{3D Object} (Cube, Sphere, Plane, dll.), \texttt{Empty}, atau \texttt{UI}. GameObject dapat diatur dalam struktur parent-child: objek child mengikuti transformasi parent. Fitur rename memungkinkan identifikasi objek dengan jelas.

\subsection{Inspector}

Setiap GameObject memiliki komponen. \class{Transform} ada secara default (Position, Rotation, Scale). Komponen lain ditambahkan via \texttt{Add Component}. Nilai dapat diubah langsung di Inspector; perubahan langsung terlihat di Scene. Tombol \texttt{Reset} mengembalikan nilai default komponen.

\subsection{Project dan Console}

Project window menyimpan semua aset proyek. Struktur folder (Materials, Scripts, Scenes) membantu organisasi aset. Console menampilkan output \texttt{Debug.Log} serta warning dan error dari script---penting untuk debugging.
