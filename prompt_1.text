TUJUAN:
Bangun buku ajar akademik profesional dalam format LaTeX dengan arsitektur modular tingkat lanjut, dengan ketentuan:
1) Dapat dikompilasi sebagai satu buku (main.tex).
2) Dapat dikompilasi per bab menggunakan package subfiles.
3) Setiap bab berada pada file subfile terpisah.
4) Setiap section berada pada file terpisah yang di-include dari file bab.
5) Mendukung OBE (Outcome-Based Education), RPS, dan sistem evaluasi pembelajaran.

B. ATURAN TEKNIS LaTeX (WAJIB)
================================================================

1) main.tex
- Gunakan \documentclass{book}.
- Load preamble.tex.
- Load package subfiles.
- Panggil bab dengan: \subfile{chapters/chXX/chXX}.
- Tidak boleh ada materi langsung di main.tex.

2) preamble.tex
- Semua package dan konfigurasi LaTeX ditempatkan di sini.
- Definisikan environment: definition, theorem, proposition, example, exercise, case study, learning outcomes.
- Atur konsistensi penomoran.

3) File bab (chXX.tex)
- Gunakan: \documentclass[../../main.tex]{subfiles}.
- Definisikan: \chapter{Judul Bab}.
- Panggil section dengan: \include{chapters/chXX/secYY}.
- Harus bisa dikompilasi mandiri.
- Tidak boleh menambahkan package.

4) File section (secYY.tex)
- Tidak boleh memiliki \documentclass.
- Hanya berisi konten \section{} atau \subsection{}.
- Dipanggil menggunakan \include dari file bab.
- Tidak boleh berdiri sendiri.
